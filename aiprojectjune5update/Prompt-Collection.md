# Prompt Collection — Sample Prompts for Native Speakers

**Purpose:** Reference document containing sample prompts across 7 languages and 7 categories, used to seed our research paper's data collection. Native speakers should treat these as inspiration, validate the ones in their language, and contribute their own.

**Target counts:**
- Telugu: 75–100 (confirmed)
- Hindi: 75–100 (confirmed)
- Kannada: 50 (confirmed)
- Korean: 30–50 (confirmed)
- Tamil, Marathi, Mandarin: 15–50 each *if contributors confirm by June 8*

**CRITICAL NOTE:** Many examples below were drafted by Claude (an AI) based on pattern-matching. **Some may have grammar errors, awkward phrasing, or unnatural spellings.** Native speakers must validate, correct, and expand them before they enter the final dataset.

---

## How to Use This Document

1. **Read the 7 categories below.** Every language's prompt set should cover all 7 categories proportionally.
2. **Scan the sample prompts for your language.** Mark any that are wrong, awkward, or unnatural.
3. **Write your OWN prompts** following the same patterns. Capture how you would *actually* type to ChatGPT — not formal translations, not what you think the AI wants to hear.
4. **Add your prompts to the collection spreadsheet** (Google Sheet to be shared) with: prompt text, category, contributor name.

---

## The 7 Prompt Categories

| # | Category | What it tests |
|---|---|---|
| 1 | Romanized colloquial questions | Most common real-world failure — script choice + casual register |
| 2 | Code-switched everyday requests | Whether the model handles language boundaries |
| 3 | Cultural / kinship references | Whether the model knows non-English cultural concepts |
| 4 | Tasks requiring native fluency | Whether the model can produce natural output |
| 5 | Idioms / proverbs / wordplay | Whether the model handles non-literal meaning |
| 6 | Register-sensitive content | Whether the model adjusts formality correctly |
| 7 | Texting-style / messy input | Whether the model handles abbreviations, mixed scripts |

## Guidelines for Contributors

**Do:**
- Type the way you actually text or chat — abbreviations, dropped letters, mixed scripts welcome
- Include culturally specific references that a non-native speaker wouldn't immediately understand
- Mix English and your native language freely if that's how you'd naturally do it
- Pick topics you actually care about — questions you'd actually ask an AI

**Don't:**
- Write formal textbook translations — those defeat the paper's purpose
- Copy from Google Translate — the paper specifically argues GT output ≠ real user input
- Sanitize your phrasing — colloquialisms, slang, idioms are what we want
- Worry about grammar "correctness" — the point is to capture how real people actually type

## What Happens Next

Once we have ~280 prompts collected:

1. Each prompt is sent to GPT-4o, Claude, Gemini, Llama 3, and one Indic-tuned model
2. We get back ~1,400 responses
3. Native speakers score the responses on the [evaluation rubric](Paper-Execution-Plan.md#evaluation-rubric-template)
4. We compute the gap between automatic metric scores and native speaker scores
5. That gap = the paper's central finding
