\section*{Reproducibility Statement}

The generation and evaluation scripts, model identifiers, prompts, decoding
parameters, and aggregate results are maintained in the accompanying anonymous
artifact. Before submission, the artifact will include a clean input manifest,
software versions, hardware details, and commands required to reproduce every
table.

\section*{Use of Language Models}

Language models were used in the research workflow for data generation,
evaluation, code assistance, and drafting assistance. The authors reviewed all
generated text, code, and claims and remain responsible for the contents of the
paper.
