Table~\ref{tab:main-results} shows the automatic evaluation results. Rows
containing an output identical to its English source receive zero for all
metrics. Blank and malformed fields also receive zero. We retain the first
Qwen3.5-35B result for each message identifier and remove duplicate reruns.
Hindi has the highest query cosine similarity (0.735) and response cosine
similarity (0.787).

Kannada illustrates the importance of joint quality and reliability reporting.
Its response BERTScore F1 is 0.412 and its response cosine similarity is 0.455
when all 142 rows, including failures scored as zero, contribute to the mean.

Telugu uses the same 142-sample denominator as the other languages. English
copies, malformed JSON, truncated output, and repetition failures contribute
zero.
Consequently, Telugu's conditional semantic scores should not be interpreted as
a 142-record success rate.
