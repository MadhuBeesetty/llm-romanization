# Romanization Evaluation Analysis

## Metrics

- **Raw BERTScore F1:** Calculated with `bert-base-multilingual-cased` and
  `rescale_with_baseline=False`.
- **BGE cosine similarity:** Cosine similarity between English and romanized
  text embeddings generated by Ollama `bge-m3`.
- One Qwen3.5-35B generation is retained per message ID; duplicate reruns use
  the first occurrence. When either generated field is identical to its English
  source after whitespace normalization, all query and response metrics for
  that row are set to zero. Blank or malformed fields also receive zero, so all
  142 samples enter each mean.

## Results

| Language | Query BERTScore F1 | Query cosine | Response BERTScore F1 | Response cosine | Query rows | Response rows |
|---|---:|---:|---:|---:|---:|---:|
| Hindi | 0.622191 | 0.734943 | 0.638743 | 0.787291 | 142 | 142 |
| Telugu | 0.460142 | 0.522162 | 0.459341 | 0.527356 | 142 | 142 |
| Kannada | 0.513753 | 0.577052 | 0.412093 | 0.455120 | 142 | 142 |

## Analysis

After assigning zero to English-copy failures, Hindi has the highest query and
response cosine similarity.

Hindi has the highest query and response BERTScore F1. Kannada has the lowest
response scores after its blank, malformed, and English-copy failures are
included as zeros.

Every original sample enters each mean. All three languages therefore use 142
rows.

For this cross-lingual comparison, BGE-M3 cosine similarity should be treated as
the primary semantic metric. Raw BERTScore F1 is useful as a secondary metric,
but English and romanized Indian-language text do not share the same vocabulary,
which can depress or distort token-alignment scores.

## Conclusion

Based primarily on BGE-M3 cosine similarity with English-copy failures scored
as zero, the current ranking is:

1. Hindi
2. Telugu
3. Kannada

Coverage must be reported alongside these scores, especially for Kannada and
Telugu.
